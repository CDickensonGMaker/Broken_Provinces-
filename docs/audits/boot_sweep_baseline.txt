# The pre-reorganisation run is in git history one commit back.

# Compared class by class against the pre-move run, EVERY project-level class is
# identical in name and count: [Codex] unknown lore entries, [ModularRoom] doors,
# [WildernessRoom] sprites, agent_radius precision, and all 44 runtime navmesh
# parses. Three classes differ, and all three are engine noise the 4.5 -> 4.7
# migration already documented as nondeterministic:
#
#   ObjectDB instances leaked at exit    0 -> 12
#   N resources still in use at exit     0 -> 12
#   Condition "p.d == N"                13 -> 6
#
# The first two always appear as a pair and are a shutdown-ordering race in
# Godot's own teardown, after --quit-after has already fired. That was not taken
# on trust: bandit_hideout_level_1.tscn was booted five consecutive times on this
# exact tree with this exact binary and reported the leak 0, 1, 1, 0, 1 times.
# The third is a degenerate plane inside Godot's geometry code, raised by the
# same handful of scenes on 4.5 and 4.7 alike, and it got QUIETER.
#
# Read those three rows as "same as before". Read any other movement as a defect.
#
